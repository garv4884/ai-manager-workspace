## Main post (recommended)

I built a VR desk for managing AI agents. 🥽

AI agents can now work for hours on their own. But they still stall on one thing: you.
A permission prompt in one terminal. A plan waiting in another. A question buried in a chat.

So I asked: what if your agents were a team in a room?

AI Manager Workspace is a hands-first mixed-reality app for Meta Quest 3:

🤖 Every agent is a robot at its own desk, and its status is visible at a glance
🚶 When one needs you, it walks up and lays the request on your desk
👍 You decide with your hands: thumbs up to approve, thumbs down to send it back
🎯 One goal in, and a lead agent splits it into roles and tasks for the whole team
🔌 Each agent can think with a different AI (Claude, OpenAI, Gemini, local models)
🛰️ An open bridge lets real agents like Claude Code join, so when Claude Code asks "Allow this command?", the robot walks the request to you in VR

It works instantly in demo mode, with no setup.

I built it solo for the Meta VR Start Developer Competition. I was minutes late to the deadline and missed the submission, which hurt. But the app is real, it's running on my headset, and the code is open:

🔗 GitHub: https://github.com/garv4884/ai-manager-workspace

What I took away: for managing many agents, the best interface may not be a dashboard. It may be a room.

Next: polishing it for the Horizon Store. Would you use something like this? What would you want your agents to ask you in VR?
